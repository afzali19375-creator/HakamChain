# 🚀 راهنمای گام‌به‌گام اجرای حَکَم‌چین روی کامپیوتر خودتان (لوکال)

این راهنما برای کسی نوشته شده که **هیچ تجربه‌ای ندارد**. کافی است مرحله‌به‌مرحله جلو بروید. در انتها یک وب‌سایت کامل روی `http://localhost:3000` در مرورگر خودتان خواهید دید که کل چرخه «امانت‌گذاری → اختلاف → داوری حَکَم → انتقال وجه» را روی یک بلاکچین شخصی نشان می‌دهد.

---

## ۰) این دمو چه چیزی را نشان می‌دهد؟

| نقش | چه می‌کند | کدام ولت |
|---|---|---|
| **کارفرما** (کارفرمای پروژه) | پرونده می‌سازد و وجه را در قرارداد هوشمند قفل می‌کند | حساب ۱ |
| **مجری** (پیمانکار) | شاهد آپلود می‌کند و در صورت اختلاف، دعوا را اعلام می‌کند | حساب ۲ |
| **ادمین / حَکَم** (پلتفرم) | شواهد را بررسی و حکم می‌دهد؛ بک‌اند تراکنش انتقال وجه را امضا می‌کند | حساب ۰ |

روی کامپیوتر شما یک **بلاکچین شخصی (Hardhat)** بالا می‌آید که ۲۰ حساب با ۱۰٬۰۰۰ اتر آزمایشی به هر کدام می‌سازد. هیچ پول واقعی در کار نیست و به اینترنت هم نیاز ندارید.

---

## ۱) نصب پیش‌نیازها (فقط یک بار)

### ۱-۱. نصب Node.js
1. به سایت [nodejs.org](https://nodejs.org) بروید.
2. نسخه **LTS** را دانلود و نصب کنید (همه‌چیز را Next بزنید).
3. بررسی نصب: یک پنجره **PowerShell** یا **CMD** باز کنید (کلید `Win` را بزنید، بنویسید `cmd` و Enter) و دستور زیر را تایپ کنید:

```bash
node -v
```

اگر چیزی مثل `v20.x.x` یا بالاتر دیدید، همه‌چیز آماده است. (اگر پیام «شناخته‌شده نیست» دیدید، کامپیوتر را یک بار ری‌استارت کنید.)

### ۱-۲. نصب MetaMask (کیف پول)
1. در مرورگر **Chrome** به [metamask.io](https://metamask.io) بروید و افزونه را نصب کنید.
2. «Create a new wallet» را بزنید و یک کیف پول جدید بسازید (عبارت بازیابی ۱۲ کلمه‌ای را جایی یادداشت کنید — **این دمو با پول واقعی نیست** ولی عادت خوبی است).
3. رمز عبور کیف پول را یک جا یادداشت کنید؛ مرتب از شما پرسیده می‌شود.

## ۲) دانلود کد پروژه

**روش ساده (پیشنهادی):**


## ۳) نصب وابستگی‌ها

1. وارد پوشه پروژه شوید.
2. **ترفند ویندوز:** در نوار آدرس پوشه کلیک کنید، کلمه `cmd` را بنویسید و Enter بزنید — یک ترمینال همان‌جا باز می‌شود.
3. دستور زیر را اجرا کنید (۲ تا ۵ دقیقه طول می‌کشد):

```bash

```

## ۵) دیپلوی قرارداد — ترمینال شماره ۲

**یک پنجره ترمینال جدید** داخل همان پوشه پروژه باز کنید (دوباره از ترفند نوار آدرس استفاده کنید) و بزنید:

```bash

```

در انتهای خروجی یک خط مثل این می‌بینید:


## ۶) ساخت فایل `.env`

در پوشه پروژه یک فایل متنی به اسم `.env` بسازید (در Notepad: File ← Save As ← در قسمت File name بنویسید `".env"` **با گیومه** تا پسوند txt نگرفد — یا در VS Code راحت‌تر است).

این محتوا را دقیقاً داخلش بگذارید و فقط خط `CONTRACT_ADDRESS` را با آدرس کپی‌شده از مرحله قبل عوض کنید:

```env
NODE_ENV=development
PORT=3000
SESSION_SECRET=hakamchain-local-secret-123
CHAIN_ID=31337
RPC_URL_SEPOLIA=http://127.0.0.1:8545
ADMIN_PRIVATE_KEY=0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80
ADMIN_ADDRESSES=0xf39fd6e51aad88f6f4ce6ab8827279cfffb92266
CONTRACT_ADDRESS=0xآدرس_قرارداد_را_اینجا_بچسبانید
DB_STORAGE=./data/hakamchain.sqlite
```

> این فایل یعنی: «ولت ادمین پلتفرم، حساب #0 است و فقط صاحب آدرس حساب #0 می‌تواند وارد پنل حَکَم شود.»

## ۸) آماده‌سازی MetaMask برای لوکال

### ۸-۱. وارد کردن سه حساب
در افزونه MetaMask:
1. روی آیکون دایره بالا کلیک کنید ← **Import account**
2. Select type ← **Private Key**
3. کلید حساب **#1** (کارفرما) را بچسبانید ← Import
4. همین کار را برای حساب **#2** (مجری) و حساب **#0** (ادمین) تکرار کنید.

حالا ۳ حساب دارید، هر کدام ۱۰٬۰۰۰ اتر آزمایشی.

### ۸-۲. اضافه کردن شبکه لوکال
**راه آسان:** وقتی در سایت دکمه «اتصال کیف پول و ورود» را بزنید، خود MetaMask پیشنهاد می‌دهد شبکه `HakamChain Local (31337)` را اضافه کند — فقط **Approve** بزنید.

**راه دستی (اگر خودتان خواستید):** در MetaMask: آیکون شبکه بالا ← Add network ← Add network manually:

| فیلد | مقدار |
|---|---|
| Network Name | `HakamChain Local` |
| RPC URL | `http://127.0.0.1:8545` |
| Chain ID | `31337` |
| Currency Symbol | `ETH` |

## ۹) سناریوی کامل دمو (مثل یک دعوای واقعی) 🎬

### صحنه ۱ — کارفرما پروژه را امانت می‌گذارد
1. در MetaMask حساب **#1 (کارفرما)** را انتخاب کنید.
2. در سایت «اتصال کیف پول و ورود» بزنید ← امضا را در MetaMask تایید کنید (این امضا رایگان است).
3. در فرم «ایجاد قرارداد جدید»:
   - عنوان: `طراحی لوگوی فروشگاه`
   - شرح: `کارفرما مبلغ 0.01 اتر بابت طراحی لوگو واریز می‌کند`
   - آدرس کیف پول مجری: `0x3C44CdDdB6a900fa2b585dd299e03d12FA4293BC` (حساب #2)
   - مبلغ: `0.01`
4. «ایجاد قرارداد و قفل وجه» ← MetaMask باز می‌شود ← **Confirm**.
5. چند ثانیه صبر کنید — پرونده با برچسب «سپرده‌شده» در لیست ظاهر می‌شود. ✅

### صحنه ۲ — مجری شاهد می‌دهد و اختلاف اعلام می‌کند
1. بالای سایت «خروج» بزنید.
2. در MetaMask به حساب **#2 (مجری)** سوییچ کنید.
3. دوباره وارد شوید.
4. در پرونده، یک فایل (مثلاً یک عکس) به عنوان شاهد آپلود کنید — فقط هش SHA-256 فایل ذخیره می‌شود، نه خود فایل.
5. دکمه **«اعلام اختلاف (داوری حَکَم)»** را بزنید ← Confirm در MetaMask.
6. وضعیت پرونده به «در جریان داوری» تغییر می‌کند. ✅

### صحنه ۳ — حَکَم حکم می‌دهد و وجه منتقل می‌شود
1. خروج بزنید؛ در MetaMask به حساب **#0 (ادمین)** سوییچ کنید.
2. وارد شوید — خودکار به **پنل حَکَم** می‌روید (آمار + لیست همه پرونده‌ها).
3. پرونده را باز کنید: آدرس دو طرف، مبلغ، هش شواهد و تراکنش‌ها را می‌بینید.
4. در کادر «یادداشت داوری» بنویسید: `مدارک تحویل بررسی شد؛ وجه به مجری تعلق می‌گیرد`.
5. دکمه **«تایید و آزادسازی وجه به مجری»** را بزنید ← تایید کنید.
6. این بار هیچ پنجره‌ای در MetaMask باز **نمی‌شود** — چون این تراکنش را **سرور با ولت ادمین** امضا می‌کند (همان طراحی «حَکَم» در معماری پروژه).
7. وضعیت به «حکم: به نفع مجری» تغییر می‌کند. ✅

### صحنه ۴ — راستی‌آزمایی نهایی
- در MetaMask به حساب #2 (مجری) بروید: موجودی از `10000` به حدود `10000.01` ETH رسیده است. 🎉
- در پنل حَکَم، هش تراکنش حکم (resolve) کنار پرونده ثبت شده است.

## ۱۰) ری‌استارت و پاک‌سازی

- توقف: در هر دو ترمینال `Ctrl+C` بزنید.
- ⚠️ **بلاکچین محلی با ری‌استارت پاک می‌شود!** دفعه بعد که خواستید اجرا کنید، به این ترتیب عمل کنید:
  1. `npx hardhat node` (ترمینال ۱)
  2. پوشه `data` داخل پروژه را حذف کنید (دیتابیس قدیمی با زنجیره جدید نمی‌خواند)
  3. `npm run deploy:local` (ترمینال ۲) ← آدرس جدید را در `.env` بگذارید ← `npm start`
- اگر MetaMask خطای عجیب nonce یا tx receipt داد: Settings ← Advanced ← **Clear activity tab data** (فقط برای حساب مشکل‌دار).

## ۱۲) عیب‌یابی سریع

| مشکل | راه‌حل |
|---|---|
| `npm` شناخته نشد | Node.js را نصب کنید؛ کامپیوتر را ری‌استارت کنید؛ ترمینال را دوباره باز کنید |
| پورت 3000 اشغال است | در `.env` خط `PORT=3001` اضافه کنید و با پورت جدید وارد شوید |
| ورود می‌گوید «شبکه را عوض کنید» | در MetaMask شبکه `HakamChain Local` را انتخاب کنید (راهنمای ۸-۲) |
| «nonce نامعتبر» هنگام ورود | صفحه را رفرش کنید و دوباره وارد شوید (هر پیام ورود یک‌بار مصرف است) |
| دکمه‌های حکم خاکستری‌اند | یعنی `.env` ناقص است (`CONTRACT_ADDRESS` یا `ADMIN_PRIVATE_KEY`)؛ اصلاح کنید و `npm start` دوباره |
| بعد از ری‌استارت، پرونده‌ها خطا می‌دهند | پوشه `data` را حذف، قرارداد را دوباره دیپلوی و `.env` را آپدیت کنید (بخش ۱۰) |
| تراکنش در MetaMask نمی‌آید | چک کنید شبکه MetaMask همان `HakamChain Local` با ChainID `31337` باشد |

## ۱۳) ⚠️ هشدارهای امنیتی

1. کلیدهایی که در این راهنما هستند **کلیدهای عمومی و معروف Hardhat**اند — فقط برای بلاکچین شخصی خودتان. **هرگز** با این کلیدها یا این روش روی شبکه واقعی (حتی Sepolia) پول جابه‌جا نکنید.
2. برای تست واقعی روی Sepolia: یک ولت تازه در MetaMask بسازید، از فاست رایگان اتر آزمایشی بگیرید و `.env` را با آن کلید تنظیم کنید.
3. فایل `.env` هرگز نباید به گیت‌هاب یا جایی فرستاده شود (در این پروژه از قبل `.gitignore` شده است).
